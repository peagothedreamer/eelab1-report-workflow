## 1. 实验目的

1. 熟悉一阶 RC 电路的零状态响应、零输入响应过程。
2. 研究一阶 RC 电路在零输入、阶跃激励情况下响应的基本规律和特点。
3. 学习用示波器观察、分析 RC 电路的响应。
4. 从响应曲线中求 RC 电路的时间常数。

## 2. 电路设计与理论计算

### 2.1 实验电路与参数

采用讲义图 9.8.4 的重复激励电路：555 时基电路构成多谐振荡器，产生周期性方波激励；CD4066 电子开关实现电容充、放电回路的切换；555 输出的前沿同时作为示波器的扫描同步信号。

- 555 定时元件：R1 = 6.8 kΩ，R2 = 510 Ω，C1 = 0.1 μF，C2 = 0.01 μF。
- RC 充放电元件：R = 2 kΩ，C 待选（用 0.01～0.1 μF 若干只更换）。
- 10 kΩ 电位器用于调节 4066 控制电平/回路电阻，按讲义图连接。
- 示波器 CH1 测 555 输出（同步），CH2 测电容电压 u_C。

### 2.2 理论计算

**一阶 RC 电路方程：**

- 零输入响应（放电）：u_C(0−) = U0 时，u_C(t) = U0·e^(−t/τ)，i_C(t) = −(U0/R)·e^(−t/τ)。
- 零状态响应（充电）：u_C(0−) = 0、激励 US 时，u_C(t) = US·(1 − e^(−t/τ))，i_C(t) = (US/R)·e^(−t/τ)。
- 时间常数：τ = RC。零输入响应中 u_C 衰减到初始值的 36.8% 所对应的时间；零状态响应中 u_C 上升到稳态值的 63.2% 所对应的时间。

**激励周期估算（555 多谐振荡器）：**

f ≈ 1.44 / [(R1 + 2R2)·C1] = 1.44 / [(6.8 kΩ + 2×510 Ω)×0.1 μF] ≈ 1.84 kHz，T ≈ 0.54 ms，半周期 T/2 ≈ 0.27 ms。

**观测条件与 τ 取值：**

- 当 τ ≪ T/2 时，方波前、后沿分别对应完整的零状态、零输入响应，可观察到全过程。
- 当 τ ≥ T/2 时，只能观察到瞬态过程的一小部分，波形不能完整充放电。
- 取 R = 2 kΩ 时：C = 0.01 μF → τ = 20 μs（τ/T ≈ 3.7%，可看全过程）；C = 0.1 μF → τ = 0.2 ms（τ 与 T/2 相当，只能看部分过程）。

## 3. 实验步骤

1. 断电状态下按讲义图 9.8.4 搭接实验电路；先检查 555 电源（VCC、GND）和 CD4066 控制端连接，确认无误后通电。
2. 用示波器观察 555 第 3 脚输出方波，记录周期 T、频率 f 和幅度，记入表 1。
3. 用示波器观察电容电压 u_C：分别观察充电（零状态响应）和放电（零输入响应）过程，描绘 u_C 波形；注明时间轴与电压轴刻度。
4. 在零状态响应曲线上读取 u_C 上升到稳态值 63.2% 的时间；在零输入响应曲线上读取 u_C 下降到初始值 36.8% 的时间，两者即为 τ 的测量值，记入表 2。
5. 更换 C（0.01、0.033、0.1 μF），重复步骤 3、4；再调节电位器改变 R，重复测量。
6. 将 τ 的测量值与 τ = RC 的理论值比较，计算相对误差，分析误差来源（元件容差、示波器读数、开关导通电阻等）。
7. 与 OrCAD 仿真（若做）或理论波形比较，说明响应规律。
