## 1. 实验目的

1. 学习晶体管放大电路的设计方法，掌握静态工作点的设置、测量与调整方法。
2. 了解放大器的非线性失真及其与静态工作点的关系。
3. 掌握放大器电压增益、输入电阻、输出电阻、幅频响应等基本性能指标的测量方法。
4. 理解射极电阻和旁路电容的负反馈作用及对放大电路性能的影响。
5. 学习用 OrCAD 对设计电路进行仿真验证。

## 2. 电路设计与理论计算

### 2.1 已知条件与性能指标

VCC = +10 V，RL = 5.1 kΩ，Vi = 10 mV，信号源内阻 Rs = 600 Ω；要求 fL < 30 Hz，1 kHz 时 |A_V| > 15，R_i > 7.5 kΩ。晶体管选用 9013，取 β = 100，V_BE = 0.7 V，V_T = 26 mV。

电路采用讲义图 2.1.1 的分压式射极电流负反馈共射放大电路：R1、R2 分压偏置，R_E1、R_E2 为射极电阻，C_E 旁路 R_E2，C1、C2 为耦合电容。

### 2.2 设计步骤

1. **静态工作点。** 取 I_C ≈ 0.9 mA，V_B ≈ VCC/4 = 2.5 V。
   R_E = (V_B − V_BE)/I_C ≈ (2.5 − 0.7)/0.9 mA ≈ 2.0 kΩ，取 R_E1 = 120 Ω、R_E2 = 1.8 kΩ。
2. **偏置电阻。** 按 R1 : R2 = (VCC − V_B) : V_B ≈ 3 : 1，并兼顾 R_i > 7.5 kΩ，取 R2 = 22 kΩ、R1 = 68 kΩ（R1 可用固定电阻与电位器串联，便于调 Q 点）。
   戴维宁等效：V_BB = VCC·R2/(R1+R2) = 2.44 V，R_BB = R1∥R2 = 16.6 kΩ。
3. **集电极电阻。** 取 V_C ≈ VCC/2 ≈ 6 V，R_C = (VCC − V_C)/IC ≈ 4.3 kΩ。
4. **增益与 R_E1。** 精确计算 I_E = (V_BB − V_BE)/[R_E + R_BB/(1+β)] ≈ 0.837 mA，I_C ≈ 0.837 mA，r_e = 26 mV/I_E ≈ 31 Ω。
   R_C′ = R_C∥RL = 2.33 kΩ，取 R_E1 = 120 Ω，则 |A_V| = R_C′/(r_e + R_E1) ≈ 15.4 > 15。
5. **输入电阻。** R_i = R1∥R2∥[(1+β)(r_e + R_E1)] = 16.6 kΩ∥15.3 kΩ ≈ 7.9 kΩ > 7.5 kΩ。
6. **电容。** 取 C1 = C2 = 22 μF，C_E = 47 μF。
7. **验算。** 由上述元件值重新计算静态工作点与交流指标，填入表 1、表 2。

### 2.3 理论值

| 参数 | 计算式 | 理论值 |
|---|---|---|
| I_C | (V_BB − V_BE)/[R_E + R_BB/(1+β)] | 0.84 mA |
| V_E | I_E·R_E | 1.61 V |
| V_C | VCC − I_C·R_C | 6.40 V |
| V_CE | V_C − V_E | 4.80 V |
| r_e | 26 mV/I_E | 31 Ω |
| A_V（带 RL） | −R_C′/(r_e + R_E1) | −15.4 |
| A_V（空载） | −R_C/(r_e + R_E1) | −28.5 |
| R_i | R1∥R2∥(1+β)(r_e+R_E1) | 7.9 kΩ |
| R_o | ≈ R_C | 4.3 kΩ |
| f_L | 由 C1、C2、C_E 共同决定（C_E 为主） | ≈ 24 Hz |

### 2.4 仿真任务（OrCAD）

- 直流工作点分析：读取 I_C、V_CE，确认晶体管工作在放大区且 Q 点适中。
- 交流扫描分析：读取中频增益 A_V、下限截止频率 f_L、上限截止频率 f_H。
- 瞬态分析：输入 1 kHz、10 mV 正弦信号，观察输出波形及相位（反相），检查是否失真。
- 将仿真值与理论值比较，必要时微调 R_E1、R_C 或偏置电阻。
