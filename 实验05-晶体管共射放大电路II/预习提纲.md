## 1. 实验目的

1. 掌握放大电路静态工作点的调整和测量方法，了解放大器的非线性失真。
2. 掌握放大电路电压增益、输入电阻、输出电阻、通频带等主要性能指标的测量方法。
3. 理解射极电阻和旁路电容在负反馈中所起的作用及对放大电路性能的影响。
4. 通过探索实验理解静态工作点、R_E1、C_E、晶体管结电容对电路性能的影响。

## 2. 电路设计与理论计算

### 2.1 被测电路与理论值

按实验四的设计结果搭建：VCC = +10 V，R1 = 68 kΩ，R2 = 22 kΩ，R_C = 4.3 kΩ，R_E1 = 120 Ω，R_E2 = 1.8 kΩ，C1 = C2 = 22 μF，C_E = 47 μF，晶体管 9013（β ≈ 100）。

理论值：I_C ≈ 0.84 mA，V_CE ≈ 4.80 V，r_e ≈ 31 Ω，A_V（带 RL = 5.1 kΩ）≈ −15.4，A_V（空载）≈ −28.5，R_i ≈ 7.9 kΩ，R_o ≈ 4.3 kΩ，f_L ≈ 24 Hz。

### 2.2 测量原理

- **静态工作点。** 输入端对地短接，用万用表直流电压挡测 V_B、V_C、V_E，则 V_CE = V_C − V_E，I_C ≈ V_E/(R_E1+R_E2)。Q 点过高（V_C ≈ VCC）接近截止，V_CE ≤ 0.5 V 进入饱和。
- **电压增益。** 双踪示波器同时观察输入、输出，在输出不失真时 A_V = V_o(pp)/V_i(pp)，注意相位关系（共射电路反相 180°）。
- **输入电阻。** 在信号源与放大器输入端之间串入已知电阻 R（取约 5.1 kΩ），测 u_s、u_i，则 R_i = u_i·R/(u_s − u_i)。
- **输出电阻。** 分别测空载输出电压 u_o 与接入 RL 后的 u_o′，则 R_o = (u_o − u_o′)·R_L/u_o′。
- **截止频率。** 保持输入幅度不变，改变频率逐点测增益；中频增益下降 3 dB（0.707 倍）处对应 f_L、f_H，通频带 BW = f_H − f_L。
- **探索预期。**
  - R_E1 增大 → 交流负反馈加深 → |A_V| 下降、R_i 增大、增益稳定性提高。
  - C_E 减小 → 低频时旁路不充分 → f_L 升高（低频特性变差）。
  - Q 点过高 → 饱和失真（输出电压底部削波）；Q 点过低 → 截止失真（输出顶部削波）。
  - 晶体管 B、C 间并接小电容 → 密勒效应使等效输入电容增大 → f_H 降低。

**不同条件下增益理论值：**

| 条件 | 理论 \|A_V\| |
|---|---|
| C_E 接入，RL = ∞ | 28.5 |
| C_E 接入，RL = 5.1 kΩ | 15.4 |
| C_E 断开，RL = ∞ | 2.2 |
| C_E 断开，RL = 5.1 kΩ | 1.2 |

## 3. 实验步骤

1. 断电搭接电路；搭接前用万用表逐一测量各电阻、电容的实际值，记入记录表。
2. 输入端对地短接，通电；测量 V_B、V_C、V_E，计算 I_C、V_CE，判断工作状态，记入表 1。调节 R1 中的电位器，使 I_C ≈ 0.84 mA、V_CE ≈ 4.8 V。
3. 输入 1 kHz 正弦信号，调节信号源幅度使输出不失真；用示波器测 V_i(pp)、V_o(pp)，计算 A_V，观察相位差，记入表 2。
4. 分别在 C_E 接入/断开、RL = ∞/5.1 kΩ 四种条件下测量 A_V，记入表 2。
5. 串入 5.1 kΩ 电阻测量 u_s、u_i，计算 R_i；测空载与带载输出电压，计算 R_o，记入表 3。
6. 保持输入幅度不变，从低频到高频逐点测量输出电压，绘幅频特性，确定 f_L、f_H，记入表 4。
7. 观察最大不失真输出：逐渐增大输入，记录输出刚开始削波时的波形与幅度，判断失真类型。
8. 探索实验（表 5）：改变 R_E1、C_E、静态工作点，在 B、C 间并接数百 pF 电容，分别测量并记录现象。
9. 将测量值与理论值、仿真值比较，分析误差。
