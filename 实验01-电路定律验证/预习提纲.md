## 1. 实验目的

1. 验证基尔霍夫电流定律（KCL）与电压定律（KVL）的正确性，加深对基尔霍夫定律的理解。
2. 实验研究叠加定理的正确性，认识叠加定理的适用范围。
3. 实验研究戴维南定理与诺顿定理，掌握有源二端口网络等效电路参数的测量方法。

## 2. 电路设计与理论计算

### 2.1 实验电路与参数

**基尔霍夫定律与叠加定理实验（讲义图 1）：** U1 = 6 V 接 F–E，U2 = 12 V 接 B–C；R1 = R3 = R4 = 510 Ω，R2 = 1 kΩ，R5 = 330 Ω。用二极管 D1（1N4007）代替 R5，阳极接 C、阴极接 D。

参考方向：I1 为 F→A，I2 为 B→A，I3 为 A→D；电压 U_XY = V_X − V_Y；回路电流正方向取 ADEFA、BADCB、FBCEF。

**戴维南、诺顿实验（讲义图 5）：** Us = 6 V，Is = 8 mA，RL 为可调负载；等效内阻 R0 = 330 Ω + 510 Ω = 840 Ω。

### 2.2 理论计算

- KCL：任一节点 ΣI = 0；KVL：任一闭合回路 ΣU = 0。定律只取决于电路拓扑，与元件是否线性无关，含二极管的电路仍然成立。
- 叠加定理：线性电路中，各独立电源单独作用产生的电流、电压可按代数和叠加；某电源不作用时，电压源短路、电流源开路。非线性电路不成立，功率不能叠加。
- 戴维南、诺顿：U_OC = U_开，I_SC = I_短，R0 = U_OC / I_SC；可将网络内独立源置零后求端口等效电阻。测量方法有开路—短路法、伏安法、半电压法（RL = R0 时 |U_L| = |U_OC|/2）。

**理论电流值（节点法计算）：**

| 元件 | 电源状态 | I1（mA） | I2（mA） | I3（mA） |
|---|---|---|---|---|
| R5 | U1 单独作用 | 4.32 | −1.20 | 3.12 |
| R5 | U2 单独作用 | −2.40 | 7.19 | 4.79 |
| R5 | U1、U2 共同作用 | 1.93 | 5.99 | 7.91 |
| D1 | U1 单独作用 | 4.24 | −0.97 | 3.27 |
| D1 | U2 单独作用 | 0 | 0 | 0 |
| D1 | U1、U2 共同作用 | 3.92 | 0 | 3.92 |

二极管状态判断：U1 单独作用时导通（I_D = 0.97 mA，U_CD = 0.70 V）；U2 单独作用、两源共同作用时截止（U_CD 分别为 −12.00 V、−10.00 V）。U1 单独作用与共同作用时二极管状态不同，电流不满足叠加关系，说明非线性电路不适用叠加定理。

**戴维南、诺顿参数（以 B 点为参考）：** U_OC = −3.36 V，I_SC = −4.0 mA（以 A→B 为正），R0 = 840 Ω；半电压法在 RL = 840 Ω 时 |U_AB| = 1.68 V。外特性：U_AB = −3.36 − 0.840·I_R（I_R 单位 mA，方向 A→B）。

## 3. 实验步骤

1. 预习时按 2.1 准备电路；接线前核对元件参数，电源输出先调至 U1 = 6 V、U2 = 12 V。
2. 先接入 R5。用万用表实测 U1、U2（以实测值为准，不取电源显示值）；用电流表分别测量 I1、I2、I3，用万用表测量 U_FA、U_AB、U_AD、U_CD、U_DE，记入表 1、表 2。
3. 用 KCL、KVL 检查测量数据是否成立。
4. 叠加定理：U1 单独作用（U2 处用短路线代替，严禁短接电源两端）、U2 单独作用（U1 短路）、两源共同作用，三种状态分别测量各电流与电压，记入表 3、表 4。
5. 断电后将 R5 换为 D1（注意阳极接 C、阴极接 D），重复步骤 2～4，记入表 1～表 4。
6. 按讲义图 5 接入 Us = 6 V、Is = 8 mA。开路时测 U_OC（不接电流表），短路时测 I_SC，计算 R0，记入表 5。
7. 负载实验：在 U_AB 从 0 到开路电压之间均匀选取 6～8 个 RL 值，测 U_AB 与 I_R，记入表 6。
8. 戴维南等效验证：用 1 kΩ 电位器调至 R0，与直流稳压源（输出 U_OC）串联，改变 RL 测外特性，记入表 7。
9. 诺顿等效验证：电位器调至 R0，与恒流源（输出 I_SC）并联，改变 RL 测外特性，记入表 8。
10. 比较原网络、戴维南等效、诺顿等效的外特性，分析误差。
